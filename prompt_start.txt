# Prompt

Crie uma aplicação completa de **Contas a Pagar (Accounts Payable)** utilizando **apenas HTML, CSS e JavaScript puro (Vanilla JavaScript)**.

## Regras obrigatórias

* Não utilizar nenhum framework.
* Não utilizar React, Vue, Angular, Bootstrap, Tailwind ou qualquer biblioteca externa.
* Não utilizar TypeScript.
* Todo o código deve ser organizado em módulos JavaScript ES6.
* A arquitetura deve ser limpa e de fácil manutenção.
* Todo o armazenamento deverá funcionar no navegador utilizando LocalStorage.
* O sistema deverá funcionar 100% offline.
* Caso exista uma API configurada, deverá sincronizar automaticamente.
* Caso a API esteja indisponível, o sistema deve continuar funcionando normalmente utilizando apenas o LocalStorage.

---

# Objetivo

Criar um sistema completo de gestão de contas a pagar que possa funcionar como um PWA futuramente.

A aplicação deve possuir arquitetura preparada para sincronização com backend, porém totalmente funcional apenas no frontend.

# Segurança

A senha nunca poderá ser salva em texto puro.

Deverá ser utilizada a API nativa:

```
window.crypto.subtle
```

Utilizar SHA-256.

Caso seja necessário adicionar salt, utilizar.

Nunca armazenar senha em texto puro.

# Armazenamento

Toda alteração deverá atualizar imediatamente o LocalStorage.

Criar uma camada:

```
StorageService
```

com métodos

```
save()

update()

delete()

find()

findAll()

clear()

export()

import()
```

Nunca acessar o LocalStorage diretamente fora desta camada.

## Funcionamento

Se

```
API_ENABLED == false
```

Todo o sistema utiliza apenas o LocalStorage.

Se

```
API_ENABLED == true
```

Todas as operações passam primeiro pela API.

Caso a API falhe

Timeout

Erro

Servidor offline

Erro 500

Erro de rede

automaticamente utilizar LocalStorage.

Sem perder dados.

# Sincronização

Criar um SyncService.

Quando a API voltar:

Enviar automaticamente os registros pendentes.

Atualizar os registros locais.

Resolver conflitos usando

```

```

O registro mais recente vence.
